# Finance Planner

Личный PWA-планировщик финансов: распределение получки по счетам и расчёт платежа/досрочки по ипотеке.

Работает целиком в браузере, данные хранятся локально (localStorage), устанавливается на телефон как приложение и работает офлайн.

## Возможности

- **Получка** — ввод суммы, распределение по счетам согласно плану, расчёт остатка, свободных денег и экстра, список переводов.
- **История** — прошлые получки со снимком плана на дату получки.
- **План** — простые и составные счета, базы, версии плана, архив.
- **Ипотека** — калькулятор «День платежа».
- **Настройки** — экспорт и импорт данных в JSON.

## Стек

React 19 · TypeScript · Vite · vite-plugin-pwa · Vitest · Playwright · oxlint + Prettier. Пакетный менеджер — pnpm.

## Запуск

```bash
pnpm install
pnpm dev
```

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | dev-сервер Vite |
| `pnpm build` | проверка типов и production-сборка в `dist/` |
| `pnpm preview` | локальный просмотр сборки |
| `pnpm typecheck` | проверка типов |
| `pnpm lint` | oxlint и проверка Prettier |
| `pnpm format` | форматирование Prettier |
| `pnpm test` | unit-тесты (Vitest) |
| `pnpm e2e:install` | установка Chromium для Playwright (нужен sudo) |
| `pnpm e2e` | e2e-тесты (мобильный и десктопный viewport) |
