# Миграция схемы

Данные пользователя живут в его браузере и в экспортированных JSON — старые версии документа должны открываться всегда.

1. **Спецификация:** обнови `spec/data-model.md` (скилл `spec-change`).
2. **Типы:** измени сущности в `src/domain/types.ts` / `AppDocument` в `src/storage/document.ts`.
3. **Версия:** увеличь `SCHEMA_VERSION` на 1.
4. **Миграция** в `src/storage/migrations.ts`: функция `vN → vN+1`, чистая, без потери данных. Новые обязательные поля — с осмысленным значением по умолчанию; переименования — перенос значения; удаление поля — только если данные действительно больше не нужны (снимки получек не трогаем).
5. **Тест** в `migrations.test.ts`: документ версии N (реалистичный, с архивными счетами и парой получек) → ожидаемый документ версии N+1; плюс цепочка с самой первой версии до текущей.
6. **Импорт:** убедись, что импорт JSON старой версии проходит через ту же миграцию.
7. Коммит — с `!` в заголовке (`feat(storage)!: …`) и описанием миграции в теле.
