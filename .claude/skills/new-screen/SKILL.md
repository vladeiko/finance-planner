# Новый экран

1. **Спецификация.** Экран и маршрут должны быть в `spec/architecture.md` (разделы «Роутинг», «Экраны MVP»). Нет — сначала скилл `spec-change`.
2. **Папка** `src/ui/screens/<name>/`:
   - `<Name>Screen.tsx` — корневой компонент экрана;
   - `<Name>Screen.module.css` — корень с `container-type: inline-size`, чтобы внутри работали `@container`;
   - дочерние компоненты, нужные только этому экрану, — рядом.
3. **Маршрут** — в `src/ui/router.ts` (и вкладка в нижней панели, если экран основной).
4. **Данные** — через `useDoc(selector)` и actions из `src/app`. Любые вычисления — функциями domain; если нужной функции нет — сначала она и её тест в `src/domain`.
5. **Стили** — только токены из `tokens.css`, mobile-first, брейкпоинты middle `36rem` / big `60rem` через `@container`. Проверь светлую и тёмную тему.
6. **Проверь в браузере** на ширине телефона (~375px) и десктопа: экран открывается по прямой ссылке `#/<route>`, «назад» работает.
