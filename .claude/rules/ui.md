# Слой ui

- Компоненты ничего не считают: суммы, остатки, досрочка — из domain (через app). В JSX нет арифметики над деньгами.
- Данные читаются через `useDoc`, изменения — через actions стора.
- Деньги показываются через `ui/lib/formatMoney`, вводятся через `MoneyInput` / `parseMoney`.
- Стили — CSS Modules рядом с компонентом (`Name.module.css`) + переменные из `ui/styles/tokens.css`. Хардкод цветов, отступов, радиусов запрещён — только `var(--…)`. Нужного токена нет — добавь в `tokens.css`.
- Mobile-first. Адаптив — `@container` с брейкпоинтами из `spec/architecture.md` (middle `36rem`, big `60rem`). SCSS не используем; вложенность — нативная.
- Светлая и тёмная тема работают через токены.
- Экран — папка в `ui/screens/<name>/`; всё, что нужно только ему, лежит там же. Переиспользуемое — в `ui/components/`. Новый экран — скилл `new-screen`.
- Навигация — только через свой hash-роутер `ui/router.ts`.
- Доступность: у полей ввода есть подписи, у кнопок — понятный текст; числовые поля открывают цифровую клавиатуру на телефоне (`inputMode="decimal"`).
