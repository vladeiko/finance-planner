# Слой domain

- Только чистые функции и типы. Нельзя импортировать React, `src/storage`, `src/app`, `src/ui`, браузерные API.
- Нельзя брать время и случайность из системы (`Date.now()`, `new Date()`, `crypto.randomUUID()`, `Math.random()`). «Сегодня» и id приходят параметром.
- Деньги — целые копейки (`Money`). Никаких float в расчётах; деление — только через функции `money.ts`, которые явно решают, куда уходит остаток копейки. Форматирование для показа — не здесь, а в `ui/lib`.
- Даты — строки `YYYY-MM-DD`.
- Каждая экспортируемая функция покрыта тестом в соседнем `*.test.ts`. Примеры из `spec/product.md` (таблицы остатка, ипотеки) обязательно превращаются в тесты один к одному.
- Формулы реализуются строго как в `spec/product.md`. Видишь, что формула в спеке неполная или ошибочная, — остановись и спроси, не додумывай.
- Функции не мутируют аргументы.
