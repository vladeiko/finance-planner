# Слой app

- Стор — модуль-синглтон `createStore` + `useDoc(selector)` на `useSyncExternalStore` (см. `spec/architecture.md`, «Состояние»). Без Context-провайдеров для данных и без библиотек состояния.
- Actions — функции `(doc, ...args) → новый doc`, без мутаций. Только здесь проставляются `id` (`crypto.randomUUID()`), `updatedAt`, `deletedAt`.
- Расчёты денег — только вызовом функций domain.
- Селекторы `useDoc` возвращают существующие ссылки из документа. Производные массивы/объекты — через `useMemo` поверх `useDoc`.
- Получка при сохранении фиксируется снимком итоговых чисел; изменение плана не трогает существующие получки.
