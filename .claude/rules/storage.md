# Слой storage

- Не знает о React. Импортирует из domain только типы.
- Формат документа описан в `spec/data-model.md`; код и спека должны совпадать.
- **Любое изменение формата документа** = скилл `schema-migration`: увеличить `SCHEMA_VERSION`, написать миграцию со старой версии, тест миграции, обновить `data-model.md`.
- Ничего не удаляем физически: удаление — `deletedAt`. Старые получки должны продолжать отображаться.
- Импорт JSON всегда проходит валидацию и миграцию; битый файл не должен затереть текущие данные.
- Ошибки доступа к `localStorage` (приватный режим, переполнение) обрабатываются и показываются пользователю, а не глотаются.
